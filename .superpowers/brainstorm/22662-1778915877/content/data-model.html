第 2 节：数据模型

4 张表 — 覆盖衣物、搭配、穿搭日记、图片队列

衣物表 clothing

clothing
├── id (PK)
├── name            "白色短袖T恤"
├── category        "top" / "bottom" / "dress" / "outerwear" / "shoes" / "accessory"
├── subcategory     "tshirt" / "shirt" / "hoodie" / "jeans" / ...
├── color           "白色"
├── color_hex       "#FFFFFF"
├── style           "casual" / "office" / "sport" / "sweet" / "cool" / "gentle"
├── thickness       "thin" / "medium" / "thick" / "down"
├── temp_min        15  (适合最低温度 ℃)
├── temp_max        28  (适合最高温度 ℃)
├── image_original    Supabase Storage URL (电商原图)
├── image_naked      Supabase Storage URL (去背景透明PNG)
├── status          "active" / "stored" / "idle"
├── user_id         (预留，先不填)
└── created_at

搭配表 outfit（改进了原文档）

问题：原文档用固定字段存搭配

原方案：outfit (top_id, bottom_id, dress_id, outerwear_id, shoes_id, accessory_id)

问题：不能叠穿（衬衫+毛衣）、加围巾要改表结构、连衣裙和上衣互斥靠注释约定

改进方案：多对多关系
outfit
├── id (PK)
├── name          "通勤优雅"
├── is_recommended  系统推荐 或 用户自搭
├── weather_condition 推荐时的天气 JSON
├── is_favorite    是否收藏
└── created_at

outfit_item  ← 新增：搭配明细表
├── id (PK)
├── outfit_id (FK → outfit)
├── clothing_id (FK → clothing)
├── slot        "top" / "bottom" / "dress" / ...
└── layer_order  1, 2, 3... (同一部位叠穿顺序)

穿搭日记表 diary

diary
├── id (PK)
├── date         DATE (哪天穿了)
├── outfit_id (FK → outfit, 可空)
├── weather_info  当天天气 JSON (缓存)
├── rating       1-5 满意度
├── note         TEXT
└── created_at

图片处理队列表 image_queue

image_queue
├── id (PK)
├── clothing_id (FK → clothing)
├── original_url    电商原图 URL
├── status        "pending" / "processing" / "done" / "failed"
├── error_message   失败原因
└── created_at

用途：上传电商图 → 后台去背景 → 存入 clothing.image_naked
队列跟踪处理状态，失败时提示用户手动处理
