夸赞逻辑改进：与当前搭配联动

夸赞内容根据模特身上展示的搭配特征动态匹配，不尬夸

匹配规则

搭配特征 触发条件 夸赞方向 示例
露肩/吊带/抹胸 上衣为吊带、一字肩、抹胸类 锁骨、肩颈 "锁骨线条就是你天生的配饰"
裙子/连衣裙 下装为短裙/长裙，或穿连衣裙 腰线、腿型、气质 "这条裙子简直为你量身定做"
运动风 搭配整体风格为 sport 活力、身材线条 "运动风都能穿出超模感，服了"
通勤/正式 搭配整体风格为 office 气场、品味、干练 "这一身开会，同事以为空降了新总监"
甜美/温柔 搭配整体风格为 sweet/gentle 笑容、温柔、亲和力 "温柔到想让全世界保护你"
酷飒 搭配整体风格为 cool 气场、自信、酷感 "今天的气场两米八，走路都带BGM"
无匹配 没有特定特征命中 品味、眼光 "会挑衣服的女孩，运气不会太差"

匹配逻辑流程

1. 拿到当前展示的搭配 outfit
2. 取出搭配中所有衣物，汇总特征：
   子类标签 (吊带/裙子/卫衣/…) + 风格标签 (sport/office/…)
3. 从 compliments 表中筛选匹配标签的夸赞
4. 命中多条 → 随机选一条
5. 命中 0 条 → 使用"无匹配"通用夸赞
6. 同一天不重复（仍用 localStorage 记录）

数据表更新

compliments
├── id (PK)
├── text          (TEXT, 30字限制)
├── tags         (TEXT[], 匹配标签数组)
│                 如：{"dress", "sweet"} 或 {"cool", "top"}
├── is_fallback   (BOOLEAN, 是否为通用夸赞)
└── created_at

tags 可选值（与搭配标签一致）：
  露肩 / 裙子 / 运动 / 通勤 / 甜美 / 酷飒 / 温柔 / 通用

切换搭配时夸赞也联动更新

用户左右滑动切换搭配 1/2/3 → PraiseBanner 内容随之切换。每次看到新搭配，夸赞都是针对这套搭配的，不会出现"看卫衣搭配时夸锁骨"的违和感。

总结：夸赞不是随机的，而是跟着搭配走的。露肩才夸锁骨，裙子才夸腰线，运动才夸活力。搭配切换，夸赞也切。
