技术选型清单

层 选型 理由
前端框架 React 18 + Vite + TypeScript 文档最丰富，AI 生成代码质量最高
样式 Tailwind CSS 响应式简单，手机适配方便
路由 React Router v6 三个 Tab 切换，够用且简单
数据库 Supabase (PostgreSQL) 自带 REST API + 图片存储，零后端
2D 模特 HTML5 Canvas 图层叠加，代码量小
图片处理 @imgly/background-removal 浏览器端 AI 抠图，无需服务器
天气 和风天气 API (前端直调) 免费 1000次/天，仅需 API Key
部署 Vercel (关联 GitHub) 免费，push 代码自动部署

与原需求文档的关键差异

原文档提到了 Node.js/Python 后端 → 取消，全部用 Supabase BaaS 替代

原文档提到了 Three.js → MVP 不用，改用 Canvas 2D 图层叠加

原文档提到了 Ant Design → 换成 Tailwind CSS，移动端响应式更灵活

新增 @imgly/background-removal 用于电商图片自动去背景
